# SB-2026-08-19-002: Current DOCX locked during full-document scan

- First observed: 2026-08-19
- Last observed: 2026-08-19
- Status: closed
- Phase/task: Organize and explain the full research document
- Environment: Windows PowerShell in the `router_model` workspace
- Version/commit: not applicable

## Symptom and impact

The normal DOCX archive reader could not open the current research document because another process was using it. The scan produced no document content and made no changes to the document.

## Evidence

- The archive open operation reported that the file was being used by another process.
- The prior Abstract extraction had succeeded before the lock was present.

## Cause

- Confirmed cause: the current DOCX is locked against the requested archive-reader access.
- Hypothesis: the document is open in a desktop editor or another reader.
- Rejected hypotheses: DOCX corruption; the earlier successful read contradicts corruption.

## Correction and prevention

Use a read-sharing-safe file handle. That handle successfully scanned the full document without terminating any process or modifying the locked document.

- Owner: Codex
- Verification: full-document paragraph and table extraction completed successfully with an explicit `FileShare.ReadWrite` handle on 2026-08-19.
